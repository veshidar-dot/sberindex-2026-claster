# Пульс муниципалитетов

Онлайн-конкурс СберИндекса 2026, номинация «Кластеризация»: экономическая структура российских муниципалитетов
через кластеризацию динамической атрибутированной сети.

- Методологический отчёт: [`docs/report.md`](docs/report.md)
- Интерактивный лендинг: `landing/index.html` (GitHub Pages репозитория; файл открывается и с диска)

## Идея в трёх строках

1. Лог расходов МО в каждой из 6 категорий = общая траектория страны + уровень МО + собственное отклонение z.
2. Узлы сети - 2 016 МО с пятью атрибутами пульса (эластичность к колебаниям страны, собственный декабрьский пик,
   дрейф относительно страны, скорость прихода маркетплейсов, шумность); рёбра - «движутся вместе» (корреляция
   месячных изменений z выше 99,9 % квантили нулевой модели) и «похожи по пульсу».
3. Leiden на совместной сети, 6 типов; та же сеть строится заново в 5 скользящих 12-месячных окнах.

## Результат

| Тип | МО | Пульс | Ядро* | Зарплата 2023** |
|---|---|---|---|---|
| Бюджетные районы Сибири и Севера | 735 | усилители, свой декабрь, отстают от страны | 32 % | 49 705 ₽ |
| Поволжье и Приуралье | 570 | отстают, переходная зона | 3 % | 50 482 ₽ |
| Промышленные города Урала и Сибири | 248 | гасители, обгоняют страну | 59 % | 63 538 ₽ |
| Растущий пояс Подмосковья и юга | 215 | быстрее всех обгоняют страну | 8 % | 58 099 ₽ |
| Москва | 134 | сильнейшие гасители | 96 % | 131 924 ₽ |
| Петербург | 114 | гасители | 85 % | 97 270 ₽ |

\* доля МО, которые во всех 12-месячных окнах держатся вместе с большинством своего типа;
\*\* Росстат, в кластеризации не участвовала: типы объясняют 43 % дисперсии лога зарплаты (случайное разбиение 0,2 %).

Сравнение 5 методов (54 конфигурации) по SW, CH, S_Dbw, AVI, AVU, ANUI, MQ против нулевой модели, выбор сведением
ранжирований (Борда, Коупленд): итог - Leiden на совместной сети, AVI 0,85, MQ 0,67. Группы сети «движутся вместе»
территориально связны, хотя география на вход не подавалась (AVI в сети дорог 0,62 против 0,44 у k-средних), но с
делением на субъекты совпадают слабо (AMI 0,27). Ошибка прогноза на месяц вперёд - 1,8 % в Москве против 4,2 % в
бюджетных районах.

## Установка

Python 3.12.

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt          # Windows: .venv\Scripts\pip
```

## Запуск

```bash
python scripts/download_data.py                    # данные в data/ (в git не хранятся); --no-rosstat - без Росстата
PYTHONPATH=src python -m pulse.run                 # Windows (PowerShell): $env:PYTHONPATH="src"; python -m pulse.run
PYTHONPATH=src python -m pytest -q tests
```

`pulse.run` выполняет по шагам (их можно запускать и отдельно):

| Шаг | Что делает | Результат |
|---|---|---|
| `python -m pulse.compare` | сети, 54 конфигурации, индексы против нулевой модели, Борда, Коупленд, устойчивость | `out/compare_grid.csv`, `out/compare_best.csv` |
| `python -m pulse.final` | итог, уверенность каждого МО, портреты типов, динамическая сеть по окнам, кластеры изменений | `out/types.csv`, `out/final.json` |
| `python -m pulse.external` | проверка: зарплата и отрасли Росстата, индекс мобильности СЗФО | `out/external.json` |
| `python -m pulse.export` | лендинг с данными внутри | `landing/index.html` |

## Конфигурация

Все параметры - в `config.yaml`: атрибуты, пороги и число соседей сетей, сетка методов, окна динамики, seed.
Локальные переопределения - `config.local.yaml` (не в git), например путь к клону
[veshidar-dot/sberindex-2026](https://github.com/veshidar-dot/sberindex-2026) с посчитанными прогнозами
(`forecasting_repo:`), чтобы связать типы с ошибкой прогноза; без него этот столбец просто не считается.

## Структура

| Файл | Что делает |
|---|---|
| `src/pulse/features.py` | разложение и атрибуты пульса, подтверждённые сдвиги |
| `src/pulse/network.py` | сети «движутся вместе» (с нулевой моделью), «похожи», дороги |
| `src/pulse/cluster.py` | методы: k-средних, Уорд со связностью, спектральная, Leiden |
| `src/pulse/compare.py` | сравнение методов и выбор |
| `src/pulse/final.py` | итог, уверенность, динамика, кластеры изменений |
| `src/pulse/external.py` | внешняя проверка |
| `src/pulse/export.py`, `landing/template.html` | лендинг |
| `src/mo_common/icvi.py` | индексы SW, CH, S_Dbw, AVI, AVU, ANUI, MQ и нулевая модель |
| `src/mo_common/data.py` | загрузка данных |
| `tests/test_icvi.py` | проверки индексов на случаях с известным ответом |
