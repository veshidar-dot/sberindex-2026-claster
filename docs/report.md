# Пульс муниципалитетов: типы МО по динамике расходов на динамической атрибутированной сети

Методологический отчёт. Онлайн-конкурс СберИндекса 2026, номинация «Кластеризация».

## 1. Коротко

- **Идея.** Муниципалитеты обычно группируют по тому, *на что* тратят жители (корзина). Мы группируем по тому, *как*
  живут их траты во времени: в такт со страной или против неё, усиливают общие колебания или гасят их, догоняют
  страну или отстают. Связь между МО в сети - не «похожи», а «движутся вместе»: месячные отклонения от траектории
  страны у них коррелируют сильнее, чем допускает нулевая модель.
- **Сеть.** 2 016 МО с полными рядами по всем 6 категориям за 24 месяца. Узлы несут 5 атрибутов пульса; рёбра двух
  видов - «движутся вместе» (15 418 рёбер) и «похожи по пульсу» (13 900); для проверки - сеть дорог (9 988).
  Динамика: та же сеть заново строится в 5 скользящих 12-месячных окнах.
- **Методы.** 5 семейств, 54 конфигурации; 7 индексов качества (SW, CH, S_Dbw, AVI, AVU, ANUI, MQ) - каждый против
  нулевой модели; выбор сведением ранжирований (Борда, Коупленд) и проверка устойчивости.
- **Итог.** Leiden на совместной сети (30 % атрибутов, 70 % «движутся вместе») - 6 типов. Средняя уверенность типа
  81 %, у 17 % МО ниже 60 % (граница типов).
- **Главные выводы.**
  1. *Часовые пояса потребления.* Сеть «движутся вместе», в которую география не подавалась, складывается в
     территориально связные макрорегионы (изолированность в сети дорог AVI 0,62 против 0,44 у k-средних), но с
     делением на субъекты совпадает слабо (AMI 0,27).
  2. *Тип говорит о том, чего в признаках не было.* Зарплата Росстата: типы объясняют 43 % дисперсии её логарифма
     (случайное разбиение - 0,2 %). Отраслевой профиль: «бюджетные районы» - 54 % работников в госуправлении,
     образовании и здравоохранении и 3 % в обработке; промышленные города Урала - 18 % обработки и 6 % добычи.
  3. *Тип сортирует МО по прогнозируемости.* Ошибка прогноза на месяц вперёд (наша работа по прогнозированию) - 1,8 %
     в Москве и 4,2 % в бюджетных районах Сибири и Севера, в 2,4 раза больше.
  4. *Ядра и переходные зоны.* Во всех окнах вместе держатся 96 % МО Москвы, 85 % Петербурга, 59 % промышленных городов
     Урала - и лишь 3 % Поволжья и Приуралья: это переходная зона, и в ней больше всего устойчивых сдвигов (0,24 на МО).

## 3. Атрибутивная структура: пять черт пульса

Для каждой категории c лог расходов раскладывается на общую траекторию категории, уровень МО и собственное
отклонение (двусторонние эффекты на несбалансированной панели):

```
log y(i,c,t) = a(i,c) + n(c,t) + z(i,c,t)
```

Общая траектория n забирает сезонность и рост страны; z - то, что у МО своё. Атрибуты (за окно месяцев):

| Атрибут | Как считается | Смысл |
|---|---|---|
| `beta` | эластичность месячных изменений лога МО к изменениям n, медиана по категориям | усилитель (> 1) или гаситель (< 1) общих колебаний |
| `season` | z в декабре минус среднее z октября, ноября и января, %, «Все категории» | собственный декабрьский пик сверх национального |
| `drift` | наклон z «Всех категорий», % в год | МО обгоняет страну или отстаёт |
| `mkt_speed` | наклон z маркетплейсов минус наклон z «Всех категорий», % в год | насколько быстрее страны приходят маркетплейсы |
| `noise` | робастный шум z (MAD месячных изменений), медиана по категориям, % | шумность ряда |

Атрибуты переводятся в робастные z-оценки (медиана, межквартильный размах) и обрезаются на ±4. «Такт со страной»
(R² изменений МО на изменения страны) почти дублирует шумность (ранговая корреляция -0,90) и в кластеризацию не
входит, только в портреты. Доли продовольствия и маркетплейсов в корзине - тоже только для пояснения.

## 4. Сетевая структура

- **«Движутся вместе».** Для каждой пары МО - корреляция месячных изменений z по всем 6 категориям подряд
  (6 x 23 = 138 наблюдений, каждая категория стандартизована). Нулевая модель: месяцы перемешаны внутри ряда.
  Ребро есть, если корреляция выше 99,9 % квантили нулевой модели (0,266), и у каждого МО остаётся 10 сильнейших
  связей; сеть симметризуется. Над порогом оказываются 9,1 % пар при ожидаемых 0,1 %: совместное движение - реальная
  структура, а не шум. Такие пары в 5,7 раза чаще лежат в одном субъекте и в среднем ближе по дорогам (1 571 км
  против 2 554).
- **«Похожи по пульсу».** 10 ближайших соседей в пространстве атрибутов, гауссово ядро.
- **Совместная сеть** для кластеризации: `0,3 · норм(«похожи») + 0,7 · норм(«движутся вместе»)`, где норм -
  симметричная нормировка по степеням (D^-1/2 A D^-1/2).
- **Дороги.** 8 ближайших по дорогам, вес exp(-d / 100 км) - для проверки территориальной связности и для метода
  с ограничением связности.
- **Динамика.** В каждом из 5 окон по 12 месяцев (сдвиг 3 месяца, в каждом окне ровно один декабрь) атрибуты и сеть
  «движутся вместе» строятся заново - так получается динамическая атрибутированная сеть.

## 5. Методы и их сравнение

| Метод | Что использует |
|---|---|
| k-средних | только атрибуты |
| Уорд со связностью по дорогам | атрибуты, группы - сплошные территории |
| Leiden на сети «движутся вместе» | только сеть |
| спектральная на совместной сети | атрибуты + сеть, задан K |
| **Leiden на совместной сети** | атрибуты + сеть, число групп задаёт разрешение |

Сетка: K = 4...9, вес атрибутов 0,3 / 0,5 / 0,7, разрешение Leiden 0,3...2,0; группы меньше 20 МО присоединяются к
соседней по сети. Всего 54 конфигурации.

**Индексы качества.** В пространстве атрибутов - силуэт SW, Калински-Харабаш CH (рядом CH на число МО: CH растёт с
объёмом выборки), S_Dbw. В сети «движутся вместе» - по Shalileh, Antonov, Tsyplakova (Doklady Mathematics, 2025;
AVI и AVU - Biswas, Biswas, 2017): S_kl - вес рёбер из группы k в группу l, O_k = sum_{l != k} S_kl, In_l = sum_{k != l} S_kl;

```
AVI  = mean_k S_kk / (S_kk + O_k)                         изолированность групп, больше - лучше
AVU  = (1/K) sum_k sum_{l != k} S_kl / (O_k + In_l - S_kl)  «склеенность» пар групп, меньше - лучше
ANUI = AVI / (1 + AVI · AVU)
MQ   = модулярность Ньюмана
```

MQ в положении конкурса не расшифрован - используем модулярность. Свойства, которые мы проверили тестами
(`tests/test_icvi.py`): две несвязные клики дают AVI = 1, AVU = 0, MQ = 0,5; при K = 2 AVU тождественно равен 1 для
любого разбиения; при равномерном фоне связей между группами AVU от разбиения не зависит - он меряет, нет ли пары
групп, которые стоит слить (разрезанный пополам блок даёт больший AVU, чем группа, набранная из всех блоков).

**Нулевая модель и выбор.** Индексы зависят от K, поэтому сырые значения разных K несравнимы. Для каждого K
считаем индексы при случайной перестановке меток с теми же размерами групп (10 повторов) и берём превышение над
нулём с учётом направления. Конфигурации ранжируются по семи превышениям (Борда), лучшая конфигурация каждого метода
выходит в финал, где методы сравниваются парно по семи индексам (Коупленд). Устойчивость - ARI с полным разбиением
на 80 % подвыборках (10 повторов).

| Метод (лучшая конфигурация) | K | SW | CH/N | S_Dbw | AVI | AVU | ANUI | MQ | AVI дороги | Коупленд | Устойч. |
|---|---|---|---|---|---|---|---|---|---|---|---|
| **Leiden, совместная сеть (α = 0,3, разреш. 0,7)** | 6 | 0,016 | 0,121 | 0,69 | **0,849** | 0,528 | 0,586 | **0,667** | 0,622 | **4** | 0,64 |
| спектральная, совместная (α = 0,3) | 4 | 0,027 | 0,136 | 0,86 | 0,857 | 0,523 | 0,592 | 0,563 | 0,706 | 0 | **0,89** |
| Leiden, только сеть (разреш. 0,3) | 4 | 0,029 | 0,115 | 1,13 | 0,913 | 0,589 | 0,594 | 0,629 | 0,721 | 0 | 0,73 |
| Уорд со связностью по дорогам | 6 | -0,042 | 0,090 | 0,71 | 0,690 | 0,430 | 0,532 | 0,525 | 0,815 | -2 | 0,40 |
| k-средних по атрибутам | 4 | **0,259** | **0,340** | 0,93 | 0,561 | 0,584 | 0,423 | 0,299 | 0,444 | -2 | 0,87 |

Что видно:
- **Атрибуты и сеть тянут в разные стороны.** k-средних даёт лучший силуэт, но его группы в сети разорваны
  (AVI 0,56, MQ 0,30); Leiden только по сети даёт сплочённые сообщества (AVI 0,91), неразличимые по атрибутам
  (силуэт около нуля). Совместная сеть с весом атрибутов 0,3 - лучший компромисс по семи индексам.
- **Превышения над нулём** у итога: SW +0,055, CH/N +0,121, S_Dbw лучше нуля на 1,69, AVI +0,68, ANUI +0,43,
  MQ +0,67; AVU хуже случайного на 0,04 - типы соседствуют попарно (Москва с Подмосковьем, Урал с Поволжьем), что
  AVU и фиксирует.
- **Цена:** устойчивость итога на подвыборках умеренная (ARI 0,64); спектральная с K = 4 устойчивее (0,89), но
  объединяет Москву и Петербург с соседями. Поэтому для каждого МО считаем уверенность в типе (раздел 6).

## 7. Динамика: ядра и переходные зоны

В каждом окне группа получает тип большинства своих МО. Совпадение разбиений окон с итоговым - AMI 0,39-0,50; между
соседними окнами тип сохраняют 39-68 % МО. Поскольку окно даёт лишь 66 наблюдений изменений, переход отдельного МО
частично отражает шум, поэтому главная мера - сплочённость типа (доля его МО в одной группе окна, не зависит от
нумерации групп) и ядро (МО во всех окнах вместе с большинством своего типа).

## 8. Проверка смысла

| Поволжье и Приуралье | 3,1 | 5,0 | 0,24 | 0,13 |

- **Зарплата Росстата** (2023 г., 2 016 МО) в признаках не участвовала: типы объясняют 43 % дисперсии её логарифма,
  случайное разбиение с теми же размерами - 0,2 %, 78 субъектов - 77 % (шесть типов против 78 групп).
- **Индекс мобильности СЗФО** (средняя дальность покупок): медиана 0,6 км в бюджетных районах и Поволжье против

  прогнозируемости, а переходная зона - это и зона собственных сдвигов.
- **Административная карта.** AMI типов с субъектами 0,27; Москва и Петербург выделяются сами, остальные типы
  пересекают границы субъектов (бюджетные районы - 65 субъектов).

## 10. Ограничения

- 24 месяца: окно в 12 месяцев даёт 66 наблюдений изменений, переходы отдельных МО частично шум.
- Внутригородские МО Москвы и Петербурга (248 из 2 016) образуют собственные типы - особенность данных.
- Сеть «движутся вместе» - корреляционная: общий ритм могут давать климат, вахта, туризм, одинаковая структура
  экономики; причин она не называет.
- Доли отраслей Росстата - оценка снизу (скрытые значения считаются нулём); зарплата - организаций без малого
  бизнеса.
- MQ трактуется как модулярность Ньюмана, так как в положении не расшифрован.

## 11. Воспроизводимость

```
python scripts/download_data.py     # данные в data/ (в git не хранятся)
python -m pulse.run                 # сравнение методов, итог, динамика, проверка, лендинг (около 10 минут на CPU)
python -m pytest -q tests           # проверки индексов и сетей
```

Все параметры - в `config.yaml` (атрибуты, пороги сетей, сетка методов, окна, seed 42); локальные пути - в
`config.local.yaml` (не в git), в том числе необязательный `forecasting_repo` для связи с ошибками прогноза.
Результаты: `out/compare_grid.csv`, `out/compare_best.csv`, `out/types.csv` (тип, уверенность, атрибуты, типы по окнам
для каждого МО), `out/final.json`, `out/external.json`.
